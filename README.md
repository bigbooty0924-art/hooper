# Player Path Finder

"Add an onboarding screen to our basketball app that asks the user for their Current Grade Level (6th through 12th). 

- If they select 6th-8th grade, lock the advanced NCAA recruitment features and show them a 'Skill Foundation' dashboard focused on drill consistency.

- If they select 9th-12th grade, unlock the 'D1 Recruitment Suite' including the NCAA Eligibility Tracker and Coach Outreach templates."
